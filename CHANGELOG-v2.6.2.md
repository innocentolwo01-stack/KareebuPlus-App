# Kareebu+ v2.6.2 — Universal Search

- Home search is now a true Kareebu+ global search instead of opening the ride destination flow.
- Added a dedicated universal Search screen.
- Search covers rides, Boda, Food, restaurants, Shops, groceries, pharmacies, parcel delivery, Wallet/Pay, orders, activity, account features and places.
- Results are grouped by Services, Food & restaurants, Shops & essentials, Places and Kareebu+.
- Popular search chips and Browse Kareebu+ shortcuts make the empty search state useful.
- Ride/Boda results still preselect the correct transport mode before entering the ride flow.
