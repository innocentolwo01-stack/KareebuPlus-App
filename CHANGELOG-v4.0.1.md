# Kareebu+ v4.0.1 — Real Landmark Country Selection

- Rebuilt the country selector to use real photographed landmarks rather than generated skyline/icon placeholders.
- Uganda uses a real photograph of the Independence Monument in Kampala.
- Kenya uses a real photograph of the Kenyatta International Convention Centre (KICC) in Nairobi.
- Tanzania uses a real photograph of the Dar es Salaam skyline.
- The map is now a subdued East Africa overview instead of jumping to a heavily zoomed individual-country map.
- Landmark cards now follow the approved carousel treatment: large selected photo, partially visible angled neighbouring cards, city location pill and subtle selected badge.
- Kept the approved Kareebu+ onboarding branding, 1-of-3 progress state, country selector and black Continue CTA.
- Added offline-safe fallback handling if a remote landmark photograph cannot load.
