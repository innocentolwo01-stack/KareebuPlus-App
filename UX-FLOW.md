# Kareebu+ v4.0 UX Flow

## First run

Native splash → Welcome → Select country with landmark imagery → Select city → Use my location or set location manually.

Signed-in path: Location → Phone → OTP → Profile → Preferences → Home.

Guest path: Location → Home.

Country and city become shared app context. Stores, currency, payment language, ride suggestions and AI recommendations follow the selected market.

## Home

Home is a longer marketplace feed rather than ending after Rewards:

Universal search → Kareebu AI → Services → hero promotion → local new finds → Rewards/Vouchers → Big brands → Popular stores → Weekend picks → Food → Shops → Recent activity.

Universal search remains deterministic. Kareebu AI handles natural-language intent and recommendations.

## Rides / Boda

Where to? owns destination discovery and routing:

Pickup → destination autocomplete / suggested place → real provider route + ETA + polyline → See ride options.

Choose ride then compares Boda, Economy, Comfort, XL and Delivery with distinct vehicle visuals, ETA, price, scheduling and payment context. The customer confirms before any dispatch.

## Food

Food → promotion rail → top nearby restaurants → dish categories → filters → restaurant list → menu → cart → order tracking.

## Shops

Shops → category selector → category-specific promotion banner → nearby brands/stores → filters → Storefront → basket.

Pharmacy has its own Wellness promotion treatment. Other categories receive their own relevant banner copy rather than inheriting the pharmacy creative.

## Kareebu AI

Kareebu AI can answer follow-up questions using recent conversation context and the user's selected country/city. It receives a Kareebu catalogue and returns structured recommendations plus safe app actions.

Examples:
- “I want grilled chicken” → ranked restaurant recommendations → View menu.
- “What about something cheaper?” → follow-up answer informed by recent conversation.
- “Find a pharmacy” → local pharmacy options → Open store.
- “Book me a Boda” → Boda destination flow.

AI never performs the final charge, order placement or driver dispatch. Transactional confirmation stays in the normal Kareebu+ flow.
