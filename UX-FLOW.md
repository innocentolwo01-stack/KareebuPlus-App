# Kareebu+ customer journey

## First open

Splash → Welcome → Country and city → Phone → OTP → Profile → Permissions → Home

A guest can enter Home from Welcome. Guest users can browse all services. When a guest confirms a ride, Kareebu+ requests sign-in and returns the customer to booking confirmation after authentication.

## Boda booking

Home → Rides/Boda → Destination → Ride choice → Payment → Confirm booking → Driver arriving → On trip → Trip completed → Rate and tip → Home

## Food ordering

Home/Food → Food discovery → Restaurant → Cart → Place order → Live order tracking → Orders

## Parcel

Home/Send → City or Uganda delivery → Locations → Parcel type → Payment → Orders
