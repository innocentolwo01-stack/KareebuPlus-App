# Kareebu+ V6.12 Real Merchant Photography

This prototype uses real editorial photography on restaurant and shop surfaces.
The photographs are representative category/food/retail photography. They are
NOT a claim that a photograph was captured inside, produced by, or officially
supplied by the named merchant unless a future merchant integration explicitly
provides that asset.

Merchant identity remains in the merchant name/logo. Existing local Kareebu
assets are retained as runtime fallbacks if a remote photograph cannot load.
