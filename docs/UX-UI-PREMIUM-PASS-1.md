# Kareebu Plus UX/UI Premium Pass 1

This pass improves the product shell without removing any existing V4.1 parity functionality.

## Changes

- Simplified global navigation to Home, Explore, Activity, Wallet and Account.
- Orders remain fully available inside Activity, Account and commerce flows, avoiding two overlapping history tabs.
- Added a stronger selected state to bottom navigation for faster scanning.
- Corrected the Home notification shortcut so it opens Notifications.
- Added clearer service hierarchy to Home.
- Rebuilt Activity as the cross-super-app history surface with All / Orders / Rides / Deliveries / Services filters.
- Reorganised Account into quick actions and grouped Activity, Payments & rewards, and Preferences sections.
- Added a persistent product quantity/Add-to-cart footer on long retail/pharmacy/grocery detail pages.

## UX rule

Feature parity remains locked. UX work may reorganise how users reach functionality, but it must not remove customer capabilities already mapped from the donor applications.
