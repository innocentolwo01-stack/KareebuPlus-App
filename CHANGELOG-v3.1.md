# Kareebu+ v3.1 — Compact Branded Home Marketplace

## Home header
- Rebuilt the Home header around the approved Kareebu+ wordmark.
- Full wordmark now renders uncropped on a white surface at the top-left.
- Compact wallet balance pill remains at the top-right.
- Delivery location, notification access and account/K mark are grouped into a cleaner utility row.

## Density and scale
- Reduced Home typography, search height, service-card height, icon scale and section spacing.
- Compacted bottom navigation and lower marketplace cards.
- Home now feels like a production mobile app rather than an oversized prototype.

## Real-brand marketplace demo
- Added current Uganda-facing brand examples across the Home marketplace: Carrefour Uganda, Capital Shoppers, Quality Supermarket, Goodlife Pharmacy, Jumia Uganda, Chicken Tonight and Café Javas.
- Added compact partner-style retail creative cards for food, groceries, pharmacy and tech.
- Demo-only merchant offers are explicitly identified in the data model so the prototype does not imply unsynchronised merchant promotions are live production offers.
- Added Jumia catalogue-style tech pricing example to make the product creative more realistic.

## Home information architecture
- Home order is now: brand/location → greeting → universal search → services → offers → big brands → recent activity → food → stores → rewards.
- Replaced the oversized Home recent-activity map block with a compact order/activity card containing a small route map preview.
- Preserved universal search behaviour across the whole Kareebu+ app.

## Branding
- Core Home surface is now clean white.
- Kareebu black, yellow and red remain the dominant chrome colours; green remains semantic/merchant-specific.
- Existing approved Kareebu+ logo assets are reused rather than recreated in text.
